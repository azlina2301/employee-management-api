# Docker Environment Variables

## 1. What are Environment Variables
Enviroment variables basically key-value pairs that used to provide configuration for application.

## 2. environment in Docker Compose
Defining the variable and value for the container.

## 3. ${VARIABLE} in Compose
To substitute the value.

## 4. os.getenv() in Python
To read the value.

## 5. .env File
.env file store environment variable in key-value pairs that can be used for variable subtitution.

## 6. .gitignore and Secrets
.gitignore prevent specific file being added into git and commited.

## 7. Environment Variables vs Secrets
Environment variables generally provide configuration for applications. Some environment variables may contain sensitive information, but environment variables themselves are not necessarily secrets.
