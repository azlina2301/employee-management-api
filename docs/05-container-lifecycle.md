# Docker Container Lifecycle

## 1. Container Creation
docker run --name 'container-name' create and start new container from an image.

## 2. Container Exit
The container main processes has stopped and returned exit 0, which generally indicates sucessfully completion.

## 3. docker start
docker start command is used to start existed container to be actived.

## 4. docker run
Create and start new container from an image.

## 5. docker stop
Stop a running container.

## 6. docker rm
Delete an existing container.

## 7. docker run vs docker start
docker run is the command used to create and start a new container from an image, while docker start is used to start an existing stopped container.
